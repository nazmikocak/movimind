# Marka ve Tema Kuralları

- **İsim:** Her yerde **MOVIMIND** (eski "Aliflix" kalmamalı).
- **Palet (Netflix tarzı):**
  - Kırmızı vurgu: `#E50914` (koyu `#B00710`).
  - Siyah arka planlar: `#0B0B0B` / `#141414` / `#1C1C1C`.
  - Beyaz/gri metin: `#FFFFFF` / `#B3B3B3` / `#808080`.
  - Gradyanlar: lacivert → fuşya → bordo (`#221C3A → #7A1F4B → #5A0E1B`).
  - **Mavi/cyan tonları kullanma.**
- **Logo:** Kırmızı, kalın "MOVIMIND" wordmark (`client/src/assets/movimind-logo.svg`).
- **Font:** Gövde **Inter**, başlık/marka **Poppins** (Google Fonts). Figtree kullanma.
- **Renkler her zaman** `client/src/styles/_variables.scss` token'larından gelir;
  bileşenlerde ham hex yazmaktan kaçın.
